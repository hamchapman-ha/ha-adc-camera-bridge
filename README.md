# ADC Camera Bridge

A Home Assistant app repository with one app: **Alarm.com Camera Bridge**,
which turns Alarm.com / ADT cameras into local, on-demand RTSP streams so Home
Assistant and HomeKit can show live video.

To add it: Settings → Apps → Install app → ⋮ → Repositories, then add
`https://github.com/hamchapman-ha/ha-adc-camera-bridge`.

See [adc_camera_bridge/DOCS.md](adc_camera_bridge/DOCS.md) for details.
